# 下载与安装

本教程将指引您如何下载与安装 Zinc。

## 检查系统配置

::: important
在您要在要运行 Zinc 的设备上安装 Zinc 前，都应该按照这部分的指引检查系统配置是否符合应用的需求。
:::

要运行 Zinc，您的系统必须满足以下任意一条要求：

- **Windows:** Windows 10 及以上版本的系统，x86_64 或 arm64 架构
- **Linux:** Debian 10（或其衍生版本）或更高版本，x86_64 或 arm64 架构

在检查完系统配置后，如果您的系统配置满足要求，则可以继续下一步的下载与安装操作。

## 下载 Zinc

Zinc 以 [Github Release](https://github.com/niuzhix/Zinc/releases/latest) 作为目前唯一的下载方式。

**👉 在浏览器中打开<https://github.com/niuzhix/Zinc/releases/latest>。**

在 Windows 中，应用有“依赖框架”和“含运行时”两种构建模式。顾名思义，“含运行时”版包含了应用运行所需的运行时，后续安装步骤中无需再安装 .NET 运行时。而“依赖框架”版与前者相对，不包含运行时，需要在后续步骤手动安装 .NET 运行时。您可以根据需要选择对应的版本。

还记得刚刚查看的系统信息吗？您需要根据系统信息中的架构信息下载对应架构的应用。

**👉 如果您的系统架构为 x64，直接点击 Windows 下的蓝色下载按钮下载即可。如果您的系统属于其它架构，则需要点击蓝色下载按钮旁的向下箭头展开更多的下载选项，选择对应的架构下载。**

不出意外的话，您应该会跳转到下载界面并开始下载。等待下载完成后，我们就可以将应用安装到您的设备上了。

## 安装 Zinc

在下载好 Zinc 的安装包后，我们接下来要将其安装到设备上。

在下载完成后，我们一般会得到一个压缩包。我们需要将其解压到一个文件夹中，才能开始使用 Zinc。

:::important
我们建议您将应用解压到 D 盘等非系统盘的根目录的一个独立的文件夹，如`D:\Zinc`中。文件路径最好不要有除了英文字母和数字以外的字符，以免出现奇奇怪怪的问题。
:::

:::caution

- 不要直接在压缩包内运行 Zinc。
- 解压时请解压所有文件

:::

**👉 使用压缩软件，将压缩包内的内容全部解压到一个独立的文件夹中（如`D:\Zinc`）。**

## 初始设置

在安装完成后，我们接下来就可以进入初始设置环节了。由于这部分的操作在各个系统中基本一致，故不再分系统进行讲解。

**🎉恭喜！至此您已完成了 Zinc 的安装操作。**
